# Agentic OS — O Sistema Operacional do Trabalho com IA

> Enquanto todo mundo ensina Claude Code como ferramenta, este curso ensina Claude Code, Codex e os agentes do futuro como **sistema operacional**.

Curso público gratuito do INEMA.CLUB. Do caos das ferramentas à arquitetura de agentes — alinhado com Karpathy (Software 3.0), Anthropic (Building Effective Agents, Context Engineering), MCP e A2A.

## A tese

| Era clássica | Era agêntica |
|---|---|
| Hardware (CPU/RAM/disco) | LLMs (Claude, GPT, Gemini) |
| Kernel / SO | **Agentic OS** (CLAUDE.md, skills, hooks, orquestrador) |
| Shell (bash, zsh) | **CLI agêntica** (Claude Code, Codex CLI, Gemini CLI) |
| Protocolos (TCP/IP, POSIX) | **MCP** + **A2A** |
| Linguagens (C, Python) | n8n, Make, LangGraph, Python+SDK |
| Aplicações | Agentes especializados |
| Filesystem | Silver Platters + RAG + memory blocks |
| Interrupts | Hooks (SessionStart, PostToolUse, Stop) |

## As 6 trilhas

1. **T1 — Fundamentos** — A tese das camadas, Software 3.0, jagged intelligence, 3 personas, método PRATO.
2. **T2 — Identidade** — CLAUDE.md, AGENTS.md, regras com escopo, governança first-class.
3. **T3 — Conhecimento** — Silver Platters, Pantry/Prep/Plate, Skills, MCP, Context Engineering, memória.
4. **T4 — Trabalhadores** — Orquestrador (90,2% melhor), chief-of-staff pattern, subagents, A2A.
5. **T5 — Automação** — Hooks como interrupts, n8n/Make como linguagens, Computer Use, observabilidade.
6. **T6 — Implantação** — 3 casos reais (Marco/Sally/Sana), Managed Agents, plano 30 dias, projeto final.

# Agentic OS — The Operating System for Working with AI

> While everyone teaches Claude Code as a tool, this course teaches Claude Code, Codex and the agents of the future as **operating system**.

Free public duclub course. From tool chaos to agent architecture — aligned with Karpathy (Software 3.0), Anthropic (Building Effective Agents, Context Engineering), MCP and A2A.

## The thesis

| Classical era | Agentic era |
|---|---|
| Hardware (CPU/RAM/disk) | LLMs (Claude, GPT, Gemini) |
| Kernel/OS | **Agentic OS** (CLAUDE.md, skills, hooks, orchestrator) |
| Shell (bash, zsh) | **Agentic CLI** (Claude Code, Codex CLI, Gemini CLI) |
| Protocols (TCP/IP, POSIX) | **MCP** + **A2A** |
| Languages ​​(C, Python) | n8n, Make, LangGraph, Python+SDK |
| Applications | Specialized agents |
| Filesystem | Silver Platters + RAG + memory blocks |
| Interrupts | Hooks (SessionStart, PostToolUse, Stop) |

## The 6 trails

1. **T1 — Fundamentals** — The layers thesis, Software 3.0, jagged intelligence, 3 personas, PRATO method.
2. **T2 — Identity** — CLAUDE.md, AGENTS.md, scoped rules, first-class governance.
3. **T3 — Knowledge** — Silver Platters, Pantry/Prep/Plate, Skills, MCP, Context Engineering, memory.
4. **T4 — Workers** — Orchestrator (90.2% better), chief-of-staff pattern, subagents, A2A.
5. **T5 — Automation** — Hooks as interrupts, n8n/Make as languages, Computer Use, observability.
6. **T6 — Implementation** — 3 real cases (Marco/Sally/Sana), Managed Agents, 30-day plan, final project.

MODULE 1.1

🏗️ The layer thesis: from semantic hardware to agent

The analogy that organizes everything: LLM is hardware, Agentic OS is kernel, CLI is shell, MCP is protocol, n8n is language, agents are applications.

What is it:

LLMs (Claude, GPT, Gemini) occupy the role that CPU+RAM occupied: the layer that "executes" instructions, but in natural language rather than assembly.

Why learn:

Without this abstraction you get stuck at the "which prompt to use" level and never build architecture.

Key concepts:

Tokens are bytes; context is RAM; model is CPU architecture; provider is manufacturer.

What is it:

CLAUDE.md, AGENTS.md, skills, hooks, orchestrator, memory — together they form the kernel that defines identity, rules and flow.

Why learn:

This is what separates “using AI” from “operating with AI.”

Key concepts:

Identity, knowledge, workers and automation — the 4 layers of the kernel.

What is it:

The CLI has become the default shell for serious agentic work: composability with pipes, hooks, git, direct filesystem.

Why learn:

Web/chat is for the curious. Actual operation happens at the terminal.

Key concepts:

Claude Code, Codex CLI, Gemini CLI, Cursor CLI, Aider — all CLI-first in 2026.

What is it:

MCP (Model Context Protocol) connects agent to tools/data. A2A (Agent2Agent) connects agent to agent. Full stack.

Why learn:

97 million downloads/month in Mar/2026. Linux Foundation rules. Definitive standard.

Key concepts:

Servers, clients, transports, agent cards, capability discovery.

What is it:

They are languages/IDEs for describing flows. They're not the OS — they're like Python, JS, C: means to build.

Why learn:

Know which language to choose for which problem. n8n for visual integrations, LangGraph for production graphs.

Key concepts:

Visual, declarative, imperative, agnostic, vendor-locked.

What is it:

CFO Bot, Researcher, Communicator. Each agent has its own scope, tools and SLA.

Why learn:

Without this abstraction you create "one agent for everything" and it fails at everything.

Key concepts:

Function, scope, tools, context, SLA, cost.

MODULE 1.2
1.2~35 min

🧠 Software 3.0 and Agentic Engineering

Karpathy, Sequoia Ascent 2026: Programming LLMs with prompts, context, tools, memory, and instructions is a new discipline.

What is it:

1.0 = explicit human code. 2.0 = neural network weights. 3.0 = prompts, context, tools, and memory programming LLMs.

Why learn:

You are in 3.0. Most still write in 1.0 expecting a result of 3.0.

Key concepts:

Compiler → model; library → context; debugger → trace.

What is it:

Discipline of coordinating fallible agents while preserving correctness, security, taste and maintainability.

Why learn:

Vibe coding generates scaled garbage. Engineering creates a reliable system.

Key concepts:

Coordination, fallibility, verification, taste.

What is it:

Agents can refactor 100k lines but fail to "walk 50 meters". Irregular intelligence.

Why learn:

Knowing where to delegate is half the game. The other half is knowing where NOT to delegate.

Key concepts:

Capacity × confidence; human-in-the-loop; mandatory verification.

What is it:

Karpathy went from writing 80% of the code to delegating 80%. The work unit has changed.

Why learn:

Real tipping point, not hype. Those who operate like this already deliver 5x more.

Key concepts:

Macro action, delegation chain, review-driven workflow.

What is it:

Agents don't automate tasks — they replace entire processes, redefine roles.

Why learn:

Those who treat it as automation underutilize it. Whoever treats it as a replacement reorganizes the business.

Key concepts:

Additive × substituent; paper redesign; outcome-based pricing.

What is it:

"You can outsource your thinking, but you can't outsource your understanding."

Why learn:

This is the limit of delegation. Understanding remains with the human. Always.

Key concepts:

Cognition × execution; responsibility; audit.

MODULE 1.3
1.3~30 min

⚠️ Why your AI doesn't generate results

The problem isn't a lack of AI — it's a lack of structure. Eternal improvisation × operating system.

What is it:

Without organized data, AI only amplifies the mess. Fast, wrong, scaled response.

Why learn:

It's the #1 mistake of anyone starting out. Shortcut that costs money.

Key concepts:

Garbage in × garbage out — now at scale.

What is it:

Ordering everything from scratch every time is the opposite of a system. It becomes a lottery.

Why learn:

Skill, hooks and CLAUDE.md eliminate improvisation.

Key concepts:

Repeatability, determinism, SOP.

What is it:

Agents should not read 50 PDFs. They read prepared summaries (Silver Platters).

Why learn:

Laying the groundwork is where the real value lies, not in the pretty agent.

Key concepts:

Pantry, Prep Table, Plate.

What is it:

Multiple agents in a flat line overlap. Orchestrator resolves.

Why learn:

Anthropic measured 90.2% improvement with hierarchy.

Key concepts:

Chief-of-staff, specialist, handoff.

What is it:

"Ask AI not to make a mistake" is cheerleading. Security comes from the architecture: folders, permissions, hooks.

Why learn:

In health/legal/financial, hope is negligence.

Key concepts:

Path scoping, ACL, isolation, auditing.

What is it:

No traces, no evals, no logs — you have no system, you have a black box.

Why learn:

Those who don't measure, don't govern.

Key concepts:

LangSmith, Letta Evals, Claude traces.

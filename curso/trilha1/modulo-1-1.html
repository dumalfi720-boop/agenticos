💻 LLM as semantic hardware

In the beginning, computing was about operating valves. Then transistors. Then chips.Today, computing includes a new type of hardware: the LLM. Claude, GPT, Gemini, Llama — they are the layer that "executes" instructions, but innatural language, not in assembly.

🧠The new physical layer

Like any hardware, LLM has its own characteristics that need to be respected:

  • •Tokens are bytes— minimum unit of work. Everything has a cost in tokens.
  • •Context is RAM— limited window where "execution" takes place.
  • •Model is CPU architecture— Opus 4.7 vs Haiku 4.5 = high-end vs low-power.
  • •Provider is manufacturer— Anthropic, OpenAI, Google, Meta, AWS Bedrock.
  • •Latency ≠ throughput— first response vs tokens/second are different metrics.

📊Karpathy, Sequoia Ascent 2026

"LLMs are no longer just chatbots or autocomplete. They are becoming a new programmable layer for digital work."

— Andrej Karpathy, ex-OpenAI / ex-Tesla, on defining Software 3.0.

🧬 Agentic OS as kernel

Hardware without an operating system is just silicon.LLM without Agentic OS is just a chatbot. The kernel is what transforms "semantic hardware" into something capable of performing continuous work, with identity, rules and flow.

🏗️The 4 layers of the kernel

  • 1. Identity— CLAUDE.md, AGENTS.md, scoped rules. Who the agent is.
  • 2. Knowledge— Silver Platters, MCP, skills, memory. What he knows and can seek.
  • 3. Workers— orchestrator + specialists. Who executes what.
  • 4. Automation— hooks, schedules, observability. Invisible work.

💡Core message

It's what separates"use AI" de "operate with AI". Whoever stays on loose prompts amplifies chaos. Whoever builds the kernel sets up an operation.

3

⌨️ CLI as agentic shell

In Unix, the shell (bash, zsh) is the programmatic interface to the kernel.In the agentic era, the CLI became this shell. Claude Code, Codex CLI, Gemini CLI, Cursor CLI, Aider, Replit Agent — all CLI-first in 2026. No coincidence.

✓ Why CLI won

  • ✓Composability with pipes, cron, hooks
  • ✓Git-native (worktrees, branches, commits)
  • ✓Direct access to the filesystem (without sandbox)
  • ✓Runs on remote server / SSH
  • ✓Session parallelization
  • ✓Low latency, no UI overhead

✗ Why web/chat is amateur

  • ✗Browser sandbox limits access
  • ✗No hooks, no cron, no composability
  • ✗State stuck in browser session
  • ✗Does not work on headless server
  • ✗UI becomes latency bottleneck
  • ✗Difficult to parallelize multiple sessions

🌐 MCP and A2A as protocols

TCP/IP was the protocol that made the internet possible.MCP is the TCP/IP of the agentic era— the pattern that connects agents to tools.A2A is the layer above— the protocol that connects agent to agent.

📊Adoption in numbers

  • 97 millionof downloads/month of MCP servers in Mar/2026
  • OpenAIadopted MCP in Mar/2025
  • Google DeepMindconfirmed support in Apr/2025
  • Cursor, Windsurf, Zed, JetBrains— all support MCP
  • Linux Foundationgoverns the protocol since Dec/2025
  • A2A: 150+ partners, 22k+ stars on GitHub in Apr/2026

🔄The fundamental difference

  • MCP— agent ↔ tool. "Access this database, read this file."
  • A2A— agent ↔ agent. "Negotiate with this agent from the other company."
  • Full stack: MCP + A2A. There are different layers, both necessary.
5

🔧 n8n, Make and LangGraph as languages

In classical computing, choosing Python or C or JS is choosing alanguage— the operating system does not change.In the agentic era, n8n, Make, LangGraph and Python+SDK are languages: means to build, not the system itself.

When to use which

  • n8n— visual integrations between SaaS. Self-host. 600+ nodes.
  • makeup— cloud-only, polished. Good for non-technical teams.
  • LangGraph— orchestration with state machine. Enterprise standard.
  • CrewAI— hierarchical teams, easy to get started.
  • Python + SDK— maximum control. Glue everything together.
  • Claude Code Skills— declarative slash commands in the CLI.

💡Common mistake

Treating n8n as "the system". It is a language. The system is the agentic architecture you design — Silver Platters, agents, hooks, governance. n8n is one of the tools to implement parts of it.

6

📦 Agents as applications

On a classic PC, applications areprograms with clear function— Word edits text, Photoshop edits image.Specialized agents are the applications of the agentic era: CFO Bot analyzes finances, CMO Bot reads customer voice, Researcher researches.

🎯Each agent has 5 attributes

  • Clear function— one sentence describes what he does.
  • Scope— which folders/data it touches.
  • Tools— which tools/MCPs he has access to.
  • Context (Silver Platters)— which summaries he reads.
  • SLA + cost— expected response time, token budget.

⚠️Anti-pattern

Create “one agent for everything”. Without scope, he fails at everything. Anthropic measured: hierarchy of specialists surpasses solo generalist in90.2%of research cases.

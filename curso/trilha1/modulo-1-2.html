📜 Software 1.0 → 2.0 → 3.0

Karpathy organized the history of software into 3 eras. Knowing which one you are in defines how you program.

The 3 eras

  • 1.0— human writes explicit code (logic, ifs, loops). Compiler transforms.
  • 2.0— human defines dataset + architecture, training generates the weights. Program lives in weights.
  • 3.0— human programs LLMs with prompts, context, tools, memory, instructions. LLM is the interpreter.

Quote

"Software 3.0 is human programming LLMs through prompts, context, tools, examples, memory, and instructions." —Karpathy, Sequoia Ascent 2026

2

🎯 Agentic Engineering

Karpathy replaced "vibe coding" withAgentic Engineering— the professional discipline of coordinating fallible agents while preserving correctness, security, taste and maintainability.

What does this mean in practice

  • Fallibility— assuming that the agent is wrong. System needs to absorb.
  • Coordination— multiple agents need hierarchy, roles, handoffs.
  • Verification— output goes through eval, review, or human gate.
  • Taste— human defines what is "good". Agent searches for the "correct" one.
3

🪨 Jagged Intelligence

Karpathy coined the term: agents are"jagged"— irregular. They can refactor 100k lines of code but fail to reason about walking 50 meters. Knowing where to delegate is half the game.

✓ Where to delegate

  • ✓Code refactoring with tests
  • ✓Summary of long documents
  • ✓Structured search
  • ✓Boilerplate and scaffolding

✗ Where NOT to delegate

  • ✗Complex spatial reasoning
  • ✗Irreversible decisions (delete, send)
  • ✗Final ethical/legal judgment
  • ✗Strategic business understanding
4

📈 80/20 inverted

Karpathy went from writing 80% of the code todelegate 80%. The unit of work changed from "typed lines of code" to "delegated macro actions".

Quote

"The unit of programming changed from typing lines of code to delegating larger macro actions." — Karpathy, Dec/2025

Implication

Those who operate in the new mode already deliver 5x more. Those who stay in the old way are being silently left behind.

5

🧩 Compute surrogate

Common mistake: treating agents asautomation(does the same task faster). The correct reading: agents aresubstitutes— they redefine positions and entire processes.

Examples

  • March— does not “automate” the weekly briefing. The position of “briefing person” disappears.
  • Sally— does not “automate” case scaffolding. The paralegal becomes an output reviewer.
  • Sana— does not “automate” biopsy summary. The initial reading is with the AI; valid human.
6

🎓 You don’t outsource understanding

This is perhaps Karpathy's most important quote in 2025-2026:

"You can outsource your thinking, but you can't outsource your understanding."

You can delegate the execution of the reasoning, but theunderstandingstays with the human. Always. It is what defines where the human remains — not in production, but in judgment.

Practical application

In every agent, clearly define: what itdecidealone? What does herecommendsand human approve? Where the humanneed to understandbefore signing?

3.1~50 min

🍽️ Silver Platters — summaries as filesystem

Agents read prepared briefs, not raw chaos. The bridge between data and reasoning.

What is it:

.md file or table with KPIs/summary of an area. Preprocessed for the agent.

Why learn:

It's the bridge between raw data and useful agent — without it, agents hallucinate reading PDFs.

Key concepts:

Structured summary, KPI, context ready.

What is it:

sales.csv, campaigns.xlsx, contracts.pdf → financial.md, marketing.md → agent reading.

Why learn:

Defines where preprocessing lives.

Key concepts:

ETL, summarization, freshness.

What is it:

Executive summary, KPIs, alerts, opportunities, open questions.

Why learn:

Standard avoids reinventing the wheel every week.

Key concepts:

Template, implicit schema, freshness.

What is it:

Numbers and KPIs come from Python (no LLM). Text and narrative come from the agent.

Why learn:

LLM doesn't add — Python adds.

Key concepts:

Deterministic computation, hallucination prevention.

What is it:

Each Silver Platter has TTL and timestamp. Stale platters are marked.

Why learn:

Old data kills analysis.

Key concepts:

TTL, timestamp, regeneration trigger.

What is it:

Persistent Markdown wiki incrementally compiled by the agent — entities, contradictions, syntheses.

Why learn:

It's the future of Silver Platters: alive, evolving.

Key concepts:

Incremental synthesis, entity pages, cross-links.

🍳 Pantry / Prep Table / Plate — data map

The metaphor of the kitchen that organizes where data lives, is processed and becomes action.

What is it:

Banks, systems, APIs, living spreadsheets, Drive, Notion, integrations.

Why learn:

Map of what exists BEFORE any agent.

Key concepts:

Source of truth, freshness, ownership.

What is it:

Where raw data becomes Silver Platter — cleaning, aggregation, summarization.

Why learn:

It is the context factory.

Key concepts:

ETL, summarization, normalization.

What is it:

Where prepared information becomes a brief, decision, alert, executed automation.

Why learn:

Without Plate, data does not become action — just a report.

Key concepts:

Outcome, brief, decision support.

What is it:

Diagram with 3 columns: pantry, prep, plate. Connections between data, processes, outputs.

Why learn:

Visual eliminates ambiguity.

Key concepts:

Data flow diagram, ownership, latency.

What is it:

Pantry (fresh), Prep (1h-1day), Plate (seconds).

Why learn:

Identifies who needs cron, who needs real-time.

Key concepts:

Latency, freshness budget, batch × stream.

What is it:

Milestone (Shopify+Goal+CSV → KPIs → brief). Sally (iManage+Outlook → case scaffold). Sana (EHR → biopsy summary).

Why learn:

Seeing the method applied anchors learning.

Key concepts:

Domain-specific kitchen, persona-driven design.

🛠️ Skills as living processes

Skill is infinite game. You start simple, watch for mistakes, refine. Here you learn refinement engineering.

What is it:

Reusable process with input, steps, output and examples. Slash command in Claude Code.

Why learn:

It's the way to not order everything from scratch every time.

Key concepts:

SOP, slash command, declarative behavior.

What is it:

Sequence of steps that always works. Result of the iteration.

Why learn:

Without a critical path, the agent wastes time searching.

Key concepts:

Happy path, error branches, idempotence.

What is it:

name, description, instructions, when_to_use, examples — structured markdown.

Why learn:

Standardization allows for reuse and auditing.

Key concepts:

Frontmatter, declarative, examples-driven.

What is it:

You never finish a skill — iterate. Every mistake is input to improve.

Why learn:

Right mindset avoids “one and done”.

Key concepts:

Living document, error → improvement.

What is it:

Claude Code Skills (.skill.md), OpenAI Agent Skills (Codex). Convergent concept, different syntax.

Why learn:

Your skills should run where you need them.

Key concepts:

Portability, convergence, vendor difference.

What is it:

Each skill has example cases with expected output. Automated eval when possible.

Why learn:

Untested skill regresses silently.

Key concepts:

Eval, regression, fixture.

🌐 MCP — connecting tools and data

97 million downloads/month. Linux Foundation. TCP/IP for the agentic era.

What is it:

Standardized protocol for connecting agents to external tools, data and prompts.

Why learn:

Without MCP, every integration is custom — it doesn’t scale.

Key concepts:

Server, client, transport, capability.

What is it:

Anthropic (source), OpenAI (Mar/2025), Google DeepMind (Apr/2025), Cursor, Windsurf, Zed, JetBrains.

Why learn:

It's not hype. It is a consolidated standard.

Key concepts:

Multi-vendor, governance (Linux Foundation), adoption curve.

What is it:

MCP server exposes capabilities. Agent is client. Transport: stdio, SSE, HTTP.

Why learn:

Know when to use stdio (local), SSE (cloud).

Key concepts:

Stdio, SSE, HTTP, JSON-RPC.

What is it:

Tools (actions), resources (data reading), prompts (reusable templates).

Why learn:

Knowing which to use for which case avoids anti-patterns.

Key concepts:

Tool × resource × prompt, idempotence.

What is it:

Hundreds of official and community servers — installation in 1 command.

Why learn:

Avoid rewriting known integrations.

Key concepts:

Server marketplace, composability.

What is it:

Use mcp-builder skill or Python/TypeScript SDK. Ideal for internal systems.

Why learn:

Serious companies have internal data — MCP server is the way.

Key concepts:

SDK, FastMCP, custom server.

🧠 Context Engineering — the new discipline

Anthropic, Sep/2025: not prompt engineering for agents. It is the engineering of which context produces which behavior.

What is it:

Prompt engineering was for 1 prompt → 1 response. Agent makes hundreds of calls — another discipline.

Why learn:

Whoever stays in prompt engineering loses the current era.

Key concepts:

Multi-turn, agent loop, evolution.

What is it:

Each token in the window competes for attention. Each token costs.

Why learn:

An inflated window loses signal and burns money.

Key concepts:

Token budget, attention dilution, recency.

What is it:

Instead of sending everything, send paths. Agent loads on demand via Read.

Why learn:

Reduces cost + increases focus.

Key concepts:

Lazy loading, file pointers, retrieval.

What is it:

Summarize long tool outputs, compress history, discard noise.

Why learn:

Long session without compression degenerates.

Key concepts:

Summarize, prune, post-compaction hook.

What is it:

Anthropic keeps prompt prefix cached for 5 min — 90% discount.

Why learn:

Know how to organize context in cacheable order.

Key concepts:

Cache breakpoint, stable prefix, hit rate.

What is it:

Right context, right time, right format. Three Rs of context engineering.

Why learn:

Heuristics that fit in your head.

Key concepts:

Right-time × right-amount × right-format.

💾 Memory as filesystem

Letta/MemGPT (UC Berkeley), Karpathy LLM Wiki, Claude Code 3-level memory. Memory structured like disk.

What is it:

Memory needs hierarchy, paths, permissions, TTL — filesystem characteristics.

Why learn:

Without this structure, memory becomes a disorganized pile.

Key concepts:

Hierarchy, paths, ACL, TTL.

What is it:

Core memory (in-context = RAM), archival memory (indexed = disk), recall memory (history).

Why learn:

It is the most rigorous academic implementation.

Key concepts:

Core × archive × recall, swap-in/out.

What is it:

~/.claude/CLAUDE.md, project/CLAUDE.md, subfolder/CLAUDE.md. Cascade.

Why learn:

Maps directly to hierarchical filesystem.

Key concepts:

Cascade, scope, override.

What is it:

Agent compiles memory into Markdown wiki — entities, contradictions, syntheses, cross-links.

Why learn:

Memory that enriches itself.

Key concepts:

Incremental, entity-graph, contradiction tracking.

What is it:

Embeddings + vector DB for semantic search in large files.

Why learn:

When hierarchical filesystem is not enough.

Key concepts:

Embedding, similarity, hybrid search.

What is it:

Each memory item has an owner, scope, expiration date and who can read it.

Why learn:

It's what separates memory from pollution.

Key concepts:

TTL, scope, ACL, ownership.
